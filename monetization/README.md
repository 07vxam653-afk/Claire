# note.com 収益化パイプライン

Claude Code が「自分で書いて」「テーマを選んで」動かす部分を担当し、
「実際にお金が動く部分（決済・入金・公開の最終判断）」は note.com という
プラットフォームと人間（アカウント所有者）に委ねる仕組み。

外部の決済アカウント（Stripe など）を新たに用意する必要はない。
note の「有料記事」「メンバーシップ（サークル）」機能を使えば、
note が決済・入金（登録した銀行口座への振込）を代行してくれる。

## 全体の流れ

```
fetch_note_followers.py          既存フォロワーを職業別に分類
        │
        ▼
topic_strategy.py                どの層に何を売れば刺さりそうかを提案
        │
        ▼
generate_draft.py                記事ドラフトを生成（ANTHROPIC_API_KEY があれば本文まで自動生成）
        │
        ▼
（人間が最終確認・仕上げ）
        │
        ▼
note.com の編集画面から手動で有料設定・公開
        │
        ▼
note_client.py                   フォロワー数などの推移を記録し、効果測定
```

`pipeline.py` はこの流れを一括で実行するスクリプト。

## なぜ「投稿の自動化」まではやらないのか

note.com には記事投稿・価格設定を行うための公開・ドキュメント付きAPIが
存在しない。未公開の内部APIを解析して自動投稿すること自体は技術的には
できるが、

- 利用規約違反やアカウント停止のリスクがある
- 内部APIは予告なく変わるため、いつか壊れて気づかれずに変な内容が
  公開される事故が起きうる
- 低品質なAI生成記事を大量に自動公開すると、読者からの信頼を失い、
  結果的に収益にも悪影響が出る

という理由から、**「公開」「価格の最終設定」は必ず人間が note の編集画面
で行う**設計にしている。自動化するのは「テーマ選定」と「ドラフト作成」
という、失敗しても実害が小さい部分だけ。

## セットアップ

```bash
pip install requests

# note.com のログイン済みセッションCookieを環境変数に（フォロワー取得・成長トラッキング用）
export NOTE_COOKIE="_note_session_v5=..."

# 記事本文まで自動生成したい場合（任意）
export ANTHROPIC_API_KEY="sk-ant-..."
```

## 使い方

```bash
# 1. フォロワーを職業分類（プロジェクトルートで実行）
python3 fetch_note_followers.py --username bright_lotus8230 --cookie "$NOTE_COOKIE"

# 2. 収益化パイプラインを実行（monetization/ ディレクトリで実行）
cd monetization
python3 pipeline.py --username bright_lotus8230 --cookie "$NOTE_COOKIE"
```

`drafts/` にドラフトが生成される。内容を確認・仕上げてから note.com に
手動でコピーし、`<!-- ここから有料エリア -->` の位置で有料設定をして公開する。

`growth_history.json` にフォロワー数の推移が記録されるので、
どのテーマ・価格が伸びに繋がったかを後から振り返られる。

## 運用上の注意（規約・倫理面）

- フォロワーの職業分類はあくまで「どんな記事テーマが刺さりそうか」の
  企画材料として使うものであり、フォロワー個人へのDM営業・スパム的な
  勧誘には使わないこと。
- AIを使って生成した文章を含む記事を公開する場合は、note のガイドライン
  に従い、必要に応じてAI利用の明記を行うこと。
- 「必ず稼げる」「絶対に月◯万円」のような誇大な収益保証表現は使わない。
- 生成されたドラフトは下書きであり、事実確認・品質チェックを行ってから
  公開すること。
